# Code Reviewer Skill

Master code reviewer focused on ensuring code quality, security, performance, and maintainability.

## Capabilities

### 1. Security Code Review
- OWASP Top 10 vulnerability detection.
- Input validation and sanitization.
- Authentication & authorization checks.
- Prevention of SQL injection, XSS, CSRF, and data leaks.

### 2. Performance & Scalability Analysis
- Database query optimization (N+1 query detection).
- Memory management and bundle size optimization.
- Connection pooling and timeout configurations.

### 3. Maintainability & Clean Code
- SOLID principles and DRY code enforcement.
- Type safety and strict TypeScript compliance.
- Test coverage and edge-case validation.

## Review Checklist
- [ ] Security: Input validated, auth enforced, no secrets leaked.
- [ ] Performance: No N+1 queries, async operations handled properly.
- [ ] Code Quality: Types explicitly defined, clean naming, reusable.
- [ ] Reliability: Error handling implemented, zero silent failures.
